# FS Fit

Plataforma da FS Soluções para personal trainers administrarem alunos, treinos, orientações alimentares, avaliações físicas e evolução.

## MVP inicial

- Autenticação de personal e aluno
- Cadastro e gestão de alunos
- Biblioteca de exercícios
- Criação e atribuição de treinos
- Portal do aluno
- Evolução física
- Orientações alimentares
- Check-ins

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Supabase
- Vercel
