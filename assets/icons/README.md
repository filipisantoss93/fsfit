# Ícones do FS Fit

Pasta destinada aos ícones oficiais do FS Fit para uso em:

- favicon e ícones do navegador;
- PWA e arquivos `maskable`;
- Apple Touch Icon / iOS;
- Android;
- Microsoft Tiles;
- demais tamanhos e variações necessárias.

Os arquivos do pacote de ícones devem ser enviados para esta pasta, preservando a organização por plataforma quando aplicável.
