# Validação do bundle CSS do painel

- `painel.html` carrega somente `css/painel.css` para os estilos específicos do painel.
- `css/painel.css` preserva a ordem anterior: aulas, compacto, resumo desktop, núcleo, início e visão geral.
- Os estilos globais `style.css`, `header-menu.css` e `mobile-navigation.css` permanecem separados.
- Nenhum JavaScript ou comportamento funcional foi alterado.
